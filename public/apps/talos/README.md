# TALOS — SIGINT LEO constellation feasibility & engineering study

Open `index.html` in a browser (double-click). The study is a self-contained, offline web application:
no server, no internet connection, no installation. Chrome, Edge, Safari or Firefox (2024 or later).

Structure
- `index.html` — study hub (start here), `executive_summary.html`, `how_to_use.html`
- `01_Research_Landscape/` — state of the art, operators & programmes, supplier catalogue, market & regulation, lessons learned, references
- `02_Technical_Understanding/` — system architecture, payload explorer (exploded view), emitters & link budgets, antennas, RF chain, processing & data, geolocation theory, bus, budgets, environment, risk register, roadmap & cost
- `03_Scenarios_Services/` — CONOPS, use cases, single satellite vs constellation, orbit/coverage simulator, TDOA/FDOA simulator, collection planning, products & pricing, EW database
- `04_Service_Demo/` — operations console demo, ground segment assumptions, software architecture
- `05_Orbit_Study/` — how many satellites for a given revisit (answer finder), constellation templates with benefits/drawbacks/capabilities, choosing the orbit
- `research/` — the five research notes (Markdown) the pages are built from, with sources
- `assets/data/` — the editable data model (baseline, components, emitters, risks, programmatics, suppliers, references)

Issue 0.3 — research and build dated 21 October 2026. See `how_to_use.html` for conventions and how to change numbers.
